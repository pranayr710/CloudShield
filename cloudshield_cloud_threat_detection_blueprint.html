🎯 Project Objective
The objective of this project is to develop an end-to-end machine learning system that analyzes cloud-hosted network traffic and host-level audit logs to:
  • Forecast cloud resource abuse by predicting network throughput anomalies (byte rate spikes) that signal cryptomining, DDoS amplification, or bandwidth theft.
  • Classify cloud-targeted attacks into predefined threat categories for automated security incident response.
  • Discover hidden workload behaviour patterns using unsupervised clustering on unlabelled flow statistics to profile normal vs. malicious cloud tenants.
  • Compare multiple machine learning algorithms across regression, classification, and clustering paradigms to identify the best-performing model per task.
  • Provide visual analytics and decision-support through an interactive cloud security dashboard (Streamlit/Gradio).
Regression — for precise cloud resource abuse forecasting (predicting network byte rate spikes during attacks).
Classification — for operational cloud attack-type categorization (identifying 7 attack types + benign traffic).
Clustering — for uncovering hidden cloud workload consumption patterns without labels.

🔬 Feature Engineering (Rubric B3 — Justified)
SYN Flood Ratio
Fraction of SYN packets relative to total. DDoS SYN floods push this toward 1.0 — half-open connections exhaust cloud VM connection pools.
syn_flood_ratio = syn_cnt / (syn_cnt + fin_cnt + ack_cnt + 1e-6)
Burst Index
Ratio of max to average packet size. DDoS sends uniform large packets (low burst), botnets send mixed sizes (high burst). Captures cloud workload behaviour signature.
burst_index = pkt_len_max / (pkt_len_avg + 1e-6)
Idle-Active Ratio
Cloud VMs under botnet control show periodic idle→active patterns (C&C polling). Normal users have random idle-active distributions.
idle_active_ratio = idl_avg / (atv_avg + 1e-6)
Directional Asymmetry
Download/upload imbalance. Data exfiltration = high download ratio. DDoS amplification = high upload ratio. Normal browsing ≈ balanced.
dir_asymmetry = abs(tot_fw_pk - tot_bw_pk) / (tot_fw_pk + tot_bw_pk + 1e-6)
Cloud domain justification (viva): "In cloud environments, SYN floods exhaust the VM's connection table — a finite resource billed by the provider. Our SYN flood ratio directly measures this cloud-specific resource exhaustion pattern, which is why AWS GuardDuty monitors similar metrics."
